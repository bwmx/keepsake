Set up a LocalNet environment

This deploys a fresh copy of the randomness beacon with its own VRF key and runs the beacon's daemon. It also deploys the capsule policy app and enrolls registry members, each with its own VRF and nomination keys, then starts a worker for each member. All accounts are LocalNet throwaways. One local server plays every party so you can watch the whole protocol.

Fewer eligible members per slot keeps nominations private but leaves more slots empty, so the committee size varies.

Sender

Commits the terms, freezes the registry snapshot and requests the beacon seed for a future round, all in one transaction.
